# 上位机与 USB 升级实测

2026-10-17，ATSAMD21E18A 的 DID 为 `0x1001030A`，WM8978 控制地址为 `0x1A`。上位机、CLI 和 MCP 都通过实板 USB 测试，当前应用版本为 3.0.0。

| 项目 | 结果 |
| --- | --- |
| USB 烧录 | 应用进入 HID 恢复接口，写入 20,392 字节，Flash CRC32 为 `702937F2`，重启恢复声卡 |
| 中断恢复 | 模拟传输中止后，无效应用不能启动；重新通过 USB 写入后恢复 |
| 参数控制 | 连续 24 轮 EQ、增益、高通、过采样、ALC 和限幅调节，镜像与寄存器编码符合预期，结束恢复原设置 |
| 同时录放音 | 30 秒，播放 5,760,000 字节，采集 2,880,000 字节；期间调参未增加 DMA、I²S 错误或播放欠载 |
| 参数保存 | 保存后重启读回一致，随后 USB 更新仍保留已保存设置 |
| MCP | 官方 Python SDK 完成初始化、十个工具发现、实板查询、调参、错误输入拒绝和实际 USB 烧录，进度通知通过 |
| 文件校验 | 十项用例通过，拒绝损坏、截断、错误型号、地址、向量表和越界长度 |
| 界面 | 三种窗口尺寸切页 48 次，布局稳定，最长一次约 375 ms；底部裁切和循环重排已修复 |

引导程序占 8,528 字节，分配 16 KB 并设置 BOOTPROT=1。首次安装通过 SWD 备份原 Flash 和用户配置，只改变保护位；日常升级只走 USB。此次中断测试模拟的是传输停止，没有实测拔电瞬间的所有情况，也没有测 SNR、THD 等模拟性能。

功能范围来自 [WM8978 手册](../../../Datasheets/WM8978-Rev4.5.pdf) 第 31～58 页，Flash 操作与保护来自 [SAMD21 手册](../../../Datasheets/SAMD21-DA1-DS40001882.pdf) 第 355～368 页。前面的 [耳机及麦克风人工确认](../../audio/2026-10-17/review.md) 单独保留。
