## Layout 前应解决或确定

### 1. CN2 定位孔缺失：已发现的封装问题

CN2 指定 `WM8978-import-fps:AUDIO-TH_PJ-3136-B`。当前封装有六个电气通孔焊盘，但没有机械定位孔；所附 XKB PJ-3136 图纸标有两个直径 1.60 mm 的定位孔。若采购该图纸所示器件，存在定位柱无法插入 PCB、器件不能贴板的风险。

应先按最终采购的 PJ-3136-B 图纸核对定位柱、引脚孔、插口相对板边的位置，再修正封装。不能只依靠焊盘 2/3/4 与符号对应来放行。

依据：[CN2 所附 XKB 原厂机械图](https://atta.szlcsc.com/upload/public/pdf/source/20231101/FB45AABFD04C0979FDEE8A028D0B6336.pdf)，PJ-3136 俯视图。

### 2. USB2、C86/C87、U16 的实物型号与封装尚未闭环

- USB2 只有通用 `USB_TYPE-C-16P` 封装，无可核对的制造商型号或图纸。不同 16P Type-C 座的固定脚、定位柱和舌片位置并不相同。先确定具体料号，再核对封装。
- C86/C87 为 220 µF / 16 V，分配 `CP_Elec_6.3x5.8`，但未给出有效的制造商型号。应落实容量、额定电压、直径、高度和推荐焊盘；若改变容量，需同步重新确认封装。
- U16 当前写 `WM8978GEFL/RV`，使用中心焊盘 3.1 × 3.1 mm 的通用 QFN。所引用 Rev 4.5 手册对应的更新订货码为 `WM8978CGEFL/...`，封装裸露焊盘 D2/E2 标为 3.30–3.60 mm。必须用实际订货后缀对应的机械图和推荐 land pattern 核对。器件裸露金属尺寸不等于 PCB 推荐铜皮尺寸，因此这里不能仅凭两者不同断言封装不可用。

依据：[WM8978 原厂数据手册 Rev 4.5](https://www.mouser.com/datasheet/2/76/WM8978_v4_5-1141768.pdf)，封装图与修订记录。

### 3. U1 必须避开不支持当前 I²S 架构的硅版本

本图是 WM8978 输出 BCLK/LRCLK，SAMD21 作为 I²S 从机。Microchip 勘误 DS80000760M §1.10.2、§1.10.4 指出：硅版本 A 的 I²S 不工作；硅版本 B 的外部 SCK/FS 从机模式不工作。型号 `ATSAMD21E18A` 中的末尾 A 并不是硅版本 A。

采购和固件验收应排除上述 A/B 硅版本，并通过 DSU.DID 确认。对于本型号，表中列出的后续硅版本为 C、D、H。C/D 的接收数据槽 RIGHT 对齐还有 §1.10.7 限制；建议统一使用 32-bit 时隙承载 16-bit 音频、BCLK = 64 × 48 kHz = 3.072 MHz，并按实际硅版本实施勘误规避。该对齐限制指 MCU 内部 SLOTADJ 配置，不能与 codec 的总线格式混为一谈。

依据：[Microchip SAM D21/DA1 勘误](https://ww1.microchip.com/downloads/aemDocuments/documents/MCU32/ProductDocuments/Errata/SAM-D21DA1-Family-Silicon-Errata-and-Data-Sheet-Clarification-DS80000760.pdf)，器件修订表及 §1.10。

### 4. USB 上电浪涌需要设计余量

直接接 VBUS 的 C75/C77/C92/C93 标称合计 9.6 µF，已经接近传统 USB 热插拔 10 µF 等效负载参考；3V3 端另有约 39.91 µF 的直接去耦容量，LDO 启动也会从 VBUS 取电。应考虑容差、直流偏压、LDO 启动和 codec 上电状态。

建议在电源入口预留/采用受控上升时间、合适限流值的负载开关，或通过计算和波形测量证明现有方案满足目标 USB 端口要求。直接挂在 VBUS 上的电容应留足余量。下游电容不能简单与输入电容相加判定违规；本项是尚未验证的浪涌风险。扬声器如需增加储能电容，宜放在受控电源之后，并核算压降和瞬态电流。

依据：[TI USB 电源分配应用说明 SLVA049](https://www.ti.com/lit/an/slva049/slva049.pdf)，10 µF / 44 Ω 热插拔负载及端口压降讨论。

### 5. Y1 的双负载时钟应核算驱动余量

Y1 ASE 系列规格列出的 CMOS 负载为 15 pF；WM8978 数字输入电容列为 10 pF，目前还同时驱动 MCU XIN，加上走线和焊盘寄生，余量需要确认。

现有 R73=33 Ω 可用于抑制边沿振铃，但不会消除容性负载。若无法证明满足 Y1 输出时序，选择更高负载能力的振荡器或加时钟缓冲器；若保留双分支，预留各分支源端串阻并缩短分支，首板测两端电平、边沿及过冲。增加串阻本身不能作为驱动能力不足的补救结论。

依据：[Abracon ASE 数据手册](https://abracon.com/Oscillators/ASEseries.pdf)及 [WM8978 数字输入规格](https://www.mouser.com/datasheet/2/76/WM8978_v4_5-1141768.pdf)。

## 建议的可选优化

| 改进 | 对本设计的价值与取舍 |
| --- | --- |
| U16 AVDD 支路预留 0 Ω / 磁珠位置 | 便于首板定位数字噪声耦合；配合芯片近端去耦，选择磁珠时检查压降和谐振。保持连续地平面，控制扬声器回流路径。 |
| BCLK、LRCLK 预留源端串阻 | 在 WM8978 输出端预留可调位置，可从 22–47 Ω 范围结合波形调整；短线不一定必须装高阻值。 |
| 增加调试测试点 | 5V、3V3、VDDCORE、RESET、MCLK、BCLK、LRCLK、SDA、SCL 及邻近 GND；高速时钟测试点采用小焊盘、短支路。 |
| 按耳机阻抗选择 C86/C87 | 理想一阶估算，220 µF 配 32 Ω 的截止频率约 22.6 Hz，配 16 Ω 约 45.2 Hz。若目标包括 16 Ω 耳机且重视低频，可选 470 µF，截止约 21.2 Hz；同时评估体积、容差和上电静音/爆音。 |
| 完整物料字段与保护方案 | 补齐 SW1 等器件 MPN、MLCC 耐压/介质及有效容量；按外壳和使用环境确定 VBUS、耳机接口保护。 |

## 放行条件与首板验证

正式 layout 前至少完成 CN2 封装修正、关键器件料号/封装确认、MCU 硅版本约束，并确定浪涌与时钟负载的处理方案。完成后可重新导出网表、跑 ERC 并进入完整布局布线。

现有方案尚无固件或实板证据。首板重点验证 USB 枚举/挂起/恢复、双向 I²S 连续收发、USB 音频速率匹配、扬声器最大工作点的电流和温升，以及麦克风底噪、耳机低频和爆音。原有 `review.md` 的连接检查结论仍有效，但不能替代本记录的 layout 放行条件。
